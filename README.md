# Навык Алисы «Расписание РГГМУ — ПО-Б26»

Готовая основа webhook-навыка Яндекс Алисы с расписанием группы ПО-Б26 на осенний семестр 2026/2027 года. Данные перенесены из официального PDF РГГМУ: https://www.rshu.ru/university/stud/docs_new/new/1197.pdf

## Что умеет

- «Какое расписание на сегодня?»
- «Какие пары завтра?»
- «Что у меня в четверг?»
- «Расписание на верхнюю неделю» / «Расписание на нижнюю неделю»
- «Какая первая пара в пятницу?»
- «Расписание на сегодня для первой подгруппы» / «...для второй подгруппы»

Смена верхней/нижней недели считается от недели с понедельника 07.09.2026, которая в проекте задана как верхняя. Сейчас это соответствует указанной пользователем верхней неделе 19–25 октября 2026 года.

## Быстро запустить локально

Требуется Python 3.10 или новее. Сам обработчик расписания использует стандартную библиотеку Python; для развёртывания через Gunicorn установите зависимость из `requirements.txt`.

```bash
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows:
# .venv\\Scripts\\activate
python app.py
```

Проверка состояния: откройте `http://127.0.0.1:8080/`.

Проверочный запрос к webhook:

```bash
curl -X POST http://127.0.0.1:8080/ \\
  -H 'Content-Type: application/json' \\
  -d '{"request":{"original_utterance":"Какое расписание на сегодня?"},"version":"1.0"}'
```

## Как подключить к Алисе

Webhook должен быть доступен в интернете по публичному HTTPS-адресу. Локальный адрес `127.0.0.1` или обычный адрес Wi-Fi для Яндекс Диалогов не подойдёт.

1. Создайте репозиторий GitHub и загрузите в него содержимое этой папки.
2. Разверните проект как Python Web Service на хостинге, который предоставляет постоянный HTTPS URL и не засыпает настолько, чтобы пропускать время ответа Алисы. Команда сборки: `pip install -r requirements.txt`. Команда запуска: `gunicorn --workers 2 --bind 0.0.0.0:$PORT app:app`.
3. Проверьте публичный адрес в браузере. Он должен вернуть JSON с `status: ok`.
4. Откройте https://dialogs.yandex.ru/development и нажмите «Создать диалог» → «Навык в Алисе».
5. Введите название `Расписание РГГМУ — ПО-Б26`, описание и примеры запросов из раздела ниже.
6. В настройках навыка, раздел Backend, выберите `Webhook URL` и вставьте публичный HTTPS URL вашего сервиса, включая завершающий `/`, если хостинг его требует.
7. Откройте вкладку «Тестирование» и проверьте несколько запросов. Сначала можно оставить навык приватным; публикация в каталоге не обязательна для первоначальной проверки.

Документация Яндекса: https://yandex.ru/dev/dialogs/alice/doc/ru/quickstart-visual-editors и https://yandex.ru/dev/dialogs/alice/doc/ru/test

## Тексты для карточки навыка

**Название:** Расписание РГГМУ — ПО-Б26

**Описание:** Голосовой помощник для просмотра расписания занятий группы ПО-Б26 Российского государственного гидрометеорологического университета.

**Примеры запросов:**
- Какое расписание на сегодня?
- Какие пары завтра?
- Что у меня в четверг?
- Расписание на верхнюю неделю.
- Расписание на нижнюю неделю.
- Какая первая пара в пятницу?
- Расписание для второй подгруппы на сегодня.

## Важно

1. Это готовый проект, но он не опубликован и не подключён к вашему аккаунту Яндекса автоматически: для этого нужны ваши аккаунты и размещение webhook на общедоступном HTTPS-сервисе.
2. Расписание — ручной перенос из PDF осеннего семестра 2026/2027, а не автоматическая синхронизация с сайтом. Университет предупреждает, что изменения возможны; проверяйте исходник перед выходом.
3. Некоторые занятия проходят отдельно в 1-й и 2-й подгруппах. Ответ без уточнения подгруппы может показывать оба варианта лабораторной.
4. Автоматический выбор верхней/нижней недели основан на указанном в проекте опорном понедельнике 07.09.2026. Если университет опубликует другой календарь чередования, поправьте `ANCHOR_MONDAY` в `app.py`.
